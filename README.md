## Welcome to the repo for my personal website

You can check out the website [here](https://miguelmolina95.github.io/)!

### Editing the text

All of the page text lives in Markdown files in [`content/`](content/):

| File | Section |
| --- | --- |
| `tagline.md` | One-liner under my name |
| `about.md` | About |
| `writing.md` | Writing |
| `soccer.md` | Soccer |
| `links.md` | Links (the LinkedIn/GitHub icons are in `index.html`) |

`index.html` is only the layout (HTML5 UP "Dimension" template). GitHub Pages builds it with Jekyll on push.
