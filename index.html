About

Hi, I'm Miguel! I'm a Senior Software Engineer at Lyft in New York, and I've spent the last nine years or so working in Infrastructure, building the systems that other engineers rely on to ship code and keep it running.

From 2018 to 2024 I was on the Deploys team, where I helped design Lyft's continuous deployment system. Today more than 95% of Lyft's services use it to ship to production without anyone having to push a button. In 2024 I moved to the Compute team, where I work on our Kubernetes platform. I helped build Facets and FacetController, an abstraction and controller that let us roll out infrastructure changes across the whole fleet safely, and I lead our automated resource rightsizing work so that services get the CPU and memory they actually need. I was also one of the shared execution leads across the Infrastructure teams for Lyft's launch in Europe.

Outside of work you'll usually find me watching, talking about, or traveling for soccer. There's more about that in the Soccer section.

I studied Computer Science Engineering at the University of Michigan (B.S.E., 2017). Go Blue!

Useful bash aliases

Here is part of my .bash_profile

export PS1="\[\033[1;32m\]\u\[\033[0m\]:\[\033[1;34m\]\W\[\033[0m\]$ "

# Full look at the directory
alias ll="ls -lhaG"

# Changing dirs
alias ..="cd .."
alias ...="cd ../.."
alias ....="cd ../../.."
alias .....="cd ../../../.."

# Some handy stuff
alias c="clear"
alias numFiles="echo $(ls -1 | wc -l)"
alias copypath='pwd|pbcopy'

# Process
alias ps="ps -ax"

# lock computer
alias lock='/System/Library/CoreServices/"Menu Extras"/User.menu/Contents/Resources/CGSession -suspend'

# refresh shell
alias reload_bash='source ~/.bash_profile'

# Directories made easy
function mkd() {
    mkdir -p "$@" && cd "$@"
}

# One command to git them all
function gmit() {
	git pull && git add -A && git commit -m "$@" && git push
}
